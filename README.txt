# 💗 Jogo da Franjoca

Site romântico simples com:
- página inicial;
- foto do meme;
- labirinto jogável;
- personagem chegando até o amor;
- foto de vocês;
- mensagem final;
- música.

## Coloque suas imagens

Dentro da pasta `assets`, coloque:

- `foto-inicio.jpg` → foto/meme da primeira tela
- `foto-voces.jpg` → foto de vocês na tela final
- `musica.mp3` → música que toca no final

Se quiser colocar sua cabeça no personagem no futuro, podemos trocar o emoji por uma imagem sua.

## Como testar

Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages

Suba `index.html`, `style.css`, `script.js` e a pasta `assets` para um repositório público e ative:
Settings → Pages → Deploy from a branch → main → /(root).
